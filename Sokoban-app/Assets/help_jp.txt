[ゲームルール]

プレイヤーを操作して全ての荷物を押し、ゴールのタイル（緑色のタイル）の上に
配置することが目的です。

- プレイヤーは荷物を押すことはできますが、引くことはできません。
- プレイヤーは一度に2つ以上の荷物を同時に押すことはできません。

---------------------------------
[1. 基本操作 (キーボード)] 

  矢印キー：プレイヤーの移動

  荷物は押すことのみ可能で、引くことはできません。

---------------------------------
[2. ショートカットと機能] 

  Z (長押し可) ：一手戻す (Undo)
  Y (長押し可) ：やり直す (Redo)

  PageDown   ：盤面を初期状態にリセット
  PageUp     ：戻した全ての操作をやり直す

  Ctrl + R   ：盤面を完全に再起動（リスタート）
  Ctrl + S   ：現在の盤面状態をファイルに保存

  F5         ：新しいランダムな盤面を生成
  H          ：このヘルプウィンドウを表示 
  Esc        ：ポーズメニューを開く

---------------------------------
[3. マウス操作] 

  移動可能な床をクリック：
    そのタイルまで自動で移動します。
    
  プレイヤーをクリック：
    移動可能な全てのタイルをハイライト表示します。
    
  ハイライトされたタイルをクリック：
    そのタイルへ移動します。
    
  プレイヤーを再度クリック：
    ハイライトを解除します。

---------------------------------
[4. スナップショット機能] 

  UIボタンを使用して、いつでもゲームの状態を保存・復元できます。

  スナップショットの追加 (Add Snapshot)：
    現在の盤面状態（座標、手数、コメント）をリストに保存します。

  スナップショットの読み込み (Load Snapshot)：
    保存されたスナップショットの一覧を表示します。
    保存した任意の状態を復元できます 。

  ※新しい盤面を読み込むと、スナップショットは全て消去されます。

---------------------------------
[5. UIボタンの機能]

  [盤面の読み込み (Load Board)]
  'Assets/Boards'に保存されているテキストファイルからレベルを読み込みます 。
  テキストファイル内の各文字の意味は以下の通りです ：
    ' ' : 床
    '#' : 壁
    '.' : ゴールタイル 
    '$' : 荷物（床の上）
    '*' : 荷物（ゴールの上）
    '@' : プレイヤー（床の上）
    '+' : プレイヤー（ゴールの上）
    
  [盤面の生成 (Generate Board)]
  以下のパラメータに基づき、新しいランダムなレベルを生成します：
    - Width/Height：盤面のサイズ（外壁を含む）。
    - Baggage：荷物の数。
    - Number of times reset：生成中に地形を更新する回数。
    - Number of times transportation：地形更新の前に最低限必要な荷物の移動回数。
    - wall tile rate：生成開始時にランダムに配置される壁の割合。
    - visited tile rate：生成開始時にあらかじめ「訪問済み」としてマークされるタイルの割合。
    - evaluation function：生成器が盤面の品質を評価するために使用するアルゴリズムを
      切り替えます。
    
  [盤面の保存 (Save Board)]
  現在の盤面レイアウト（壁、ゴール、初期位置）を'Assets/Boards'内の
  新しい.txtファイルに保存します。
  
  [ログの保存 (Save Log)]
  現在のセッションの全操作履歴（全ての移動とUndo）を'Assets/Logs'に保存します。
    - 注意：別の盤面に変更すると、このログは破棄されます。
    - レベルをクリアした際にも、ログは自動的に保存されます 。
